# 3-minute video script (record the screen, voice over)

**0:00-0:20 - Hook + paste.** "Every person gets an agent. The agents date each other. Here are 25 real people." Paste the 25 LinkedIn + Instagram pairs, click *Send the agents out*.

**0:20-1:00 - Reading.** Show the progress bar and live log (scraping, agent reading). Open one profile page: point at needs, hobbies, interests, values, dealbreakers, and the *Evidence the agent found* list. "Every claim traces back to a post or a job."

**1:00-1:50 - Dating.** Show triage ("each agent picks who to meet"), then the Dates tab filling live. Open one date and read two or three turns aloud. Show both agents' debriefs: score, needs met, friction. "Each agent scores the date for its own person, independently."

**1:50-2:35 - Rankings.** Open Rankings, click a person, show their top matches with mutual scores. Click the #1 match to jump to the date that earned it. Show one "not dated" entry to explain triage.

**2:35-3:00 - How.** "Apify scrapes the public profiles, Claude Sonnet builds the profile, Claude Haiku runs the dates, ranking weights my agent 60 / theirs 40. Code is public on GitHub." Stop at 3:00.

Tip: record from the exported `demo.json` (Load finished demo) so nothing waits on the network.
